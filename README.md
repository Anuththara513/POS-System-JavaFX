A comprehensive Desktop Application designed to streamline retail operations, sales tracking, and inventory management. This project focuses on providing an intuitive interface for staff while maintaining a secure and organized backend for data storage.

Key Features:

Inventory Management: Real-time tracking of stock levels and automated product updates.

Sales Transactions: Efficient checkout process with automated bill generation.

Database Integration: Secure data handling using SQL to manage customer records and sales history.

User-Friendly UI: Developed with JavaFX to ensure a responsive and professional user experience.

Technologies Used:

Frontend: JavaFX (FXML)

Backend: Java

Database: MySQL (via phpMyAdmin)

Tools: Visual Studio / NetBeans
